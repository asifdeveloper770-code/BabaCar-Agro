# AgroCraft Studio

The following generation prompt is optimized to output the frontend code, UI/UX layouts, and component architecture for this client project using modern web frameworks.

System Role & Tech Stack

Act as an expert Frontend Developer and UI/UX Designer. Build a fully functional, highly interactive web application using React, Tailwind CSS, and Framer Motion for GPU-accelerated animations.

Brand Identity & Theme

Create a cohesive design system based on the "Thiaw Agro Élevage" business identity.

Extract the color palette directly from the reference logo: use a warm wood/tan background (like the logo's texture), deep olive green for primary typography and structural elements, and a rich, earthy terracotta/chicken-orange for primary Call-to-Action (CTA) buttons and hover states.

Ensure the overall aesthetic is modern and creative, avoiding generic corporate templates.

Animations & Interactivity

Implement "crazy," eye-catching Framer Motion animations across all sections.

Use staggered fade-up reveals on scroll for all text blocks.

Add 3D tilt hover effects and GPU-accelerated scaling to all product cards and image placeholders.

Implement a smooth parallax scrolling effect for background elements.

Component Architecture & Page Structure Build a seamless navigation experience covering less than five core sections:

Hero Section: Design a high-impact split layout that guarantees visibility by prominently featuring a placeholder for the owner's picture at the front. Accompany this image with bold, animated typography highlighting their personal intention and mission.

About Us: An animated narrative section detailing the farm's story.

Services / Products: Build an interactive grid with heavy hover effects to display their core offerings: Agriculture, fruits, vegetables, and chickens. Target the copy and layout toward consumers, restaurants, and resellers.

What is Coming: Create a dedicated, visually distinct timeline or feature block focused on upcoming opportunities for immigrants to invest.

Contact & Ordering: Develop a highly styled, modern contact and ordering form with animated input borders and success state micro-interactions.

Navigation & Footer

Include a glassmorphism sticky header linking to Home, About Us, Service, Contact, and What is coming.
